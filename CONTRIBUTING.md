# Contributing

Open an issue describing the reproduction, expected result, sanitized sample, Python/APEX version, and exact command. **Never upload credentials or proprietary exports**. Run `./scripts/check.sh` before submitting a pull request. Add tests for new rules and document false positives. Make small focused changes; maintain backward-compatible JSON keys or document breaking changes. All submitted code must be original or legally redistributable under MIT. Maintainers review contributions when available; no response SLA is promised.
